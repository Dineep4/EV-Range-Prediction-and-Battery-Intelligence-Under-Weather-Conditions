# VoltWise frontend

React + Vite UI. Start with `npm install` and `npm run dev`. Configure `VITE_API_URL` via `.env.local` if FastAPI runs elsewhere; see the project root README.

Pages: Dashboard, Trip Planner, Battery Health, Model Performance, Charging Stations, Helpful Driving Tips.

The charts labelled illustrative/demo are not experimental results. Map routing, geocoding, weather and station discovery use public internet services and may be rate-limited or unavailable.
